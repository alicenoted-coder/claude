# 我的待辦（個人 todo）

一個照你習慣做的待辦清單網頁，**完全免費、不用學寫程式、不會過期**。
資料存在你自己的裝置裡，沒有別人看得到。

功能：
- 🔴🟡🟢 照**重要程度**分成高/中/低三組
- 📅 每筆可設**到期日**（會自動標「今天／明天／逾期」）
- 🔁 **重複事項**（每天／每週／每月）：打勾完成後，下一次會自動排好
- 📝 每筆可寫**備註**、加**子項目**（小步驟）
- ✅ 完成的事**保留在「已完成」**，可回頭看，也能還原
- 💾 **匯出／匯入備份**：把資料在 iPhone 和 Mac 之間搬

---

## 在 Mac 上用（最快，馬上能用）

直接用 Finder 找到這個資料夾，**用瀏覽器打開 `index.html`**（雙擊，或拖進 Safari／Chrome）。
就這樣，可以開始新增待辦了。

> 注意：用這種方式開，只有「離線快取」那一點點功能不會啟用，其它全部正常。

---

## 放到 iPhone（像一個真的 app）

要在 iPhone 用、而且想要桌面有個圖示，需要先讓這個網頁有一個網址。
最簡單免費的做法是用 **GitHub Pages**（不用付錢）：

1. 這些檔案已經在你的 GitHub repo 裡了（在 `todo/` 資料夾）。
2. 打開這個 repo 的網頁 → 上方 **Settings**（設定）。
3. 左邊選 **Pages**。
4. 「Build and deployment」→ Source 選 **Deploy from a branch**。
5. Branch 選你的分支（或先把這個分支合併到 `main` 再選 `main`），資料夾選 **/ (root)**，按 **Save**。
6. 等一兩分鐘，頁面上會出現一個網址，例如：
   `https://你的帳號.github.io/claude/todo/`
7. 用 **iPhone 的 Safari** 打開那個網址。
8. 按底下的「分享」鈕 → **加入主畫面**。
9. 桌面就會出現「待辦」圖示，點開是全螢幕，跟 app 一樣。

Mac 上也可以打開同一個網址使用。

## 兩台裝置共用同一份資料

這個 app 不需要帳號，所以資料**各存各的**（iPhone 一份、Mac 一份，不會自動同步）。
要讓兩邊一致時：

- 在有最新資料的那一台，點下方 **「⬇️ 匯出備份」**，會存成一個 `.json` 檔。
- 把檔案傳到另一台（AirDrop、郵件、雲端都行）。
- 在另一台點 **「⬆️ 匯入備份」**，選那個檔案 → 完成。

平常也建議偶爾匯出一份備份留著，比較安心。
